# Prototypy (zamrożone)

`strona-glowna-A-granatowy.html` to prototyp strony głównej na desktop, wybrany przez Zleceniodawcę (ADR 0002). Służy wyłącznie jako przykład i nie jest dalej rozwijany. Zmiany robimy w design systemie, a docelowo w `theme.json`. Uwagi klienta: `docs/design/uwagi-klienta.md`.

Wariant B, „Jasny”, został odrzucony i usunięty.

Nieaktualne elementy prototypu (nie poprawiamy ich, bo prototyp jest zamrożony): 3 karty filarów prowadzące do nieistniejących hubów (obowiązuje 6 Kart ofert, patrz `docs/design/decyzje-ds-i-layoutow.md`), CtaBar z jednym przyciskiem, okruszki w Hero, MapFacade z samym linkiem i wiersz godzin, `sp-grid--4` od 960 px.
